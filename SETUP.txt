# Flexlyf Trade Intelligence CMS

Files
- trade-intelligence.html — public Trade Intelligence page; loads published articles from data/news.json.
- admin-news.php — password-protected admin panel to add/edit/publish/delete articles.
- news-article.php — public full-article view.
- data/news.json — JSON content store.
- news-images/ — uploaded article images.
- config.php — admin password hash and file paths.

## Default starter password
The package is initialized with this temporary password: `FlexlyfCMS!2026`
Change it before publishing the admin page.

Generate a new password hash:
```
php -r "echo password_hash('YOUR_NEW_PASSWORD', PASSWORD_DEFAULT), PHP_EOL;"
```
Then replace `REPLACE_WITH_BCRYPT_HASH` in `config.php`.

## Hosting
This implementation requires PHP 8+ and write permission for `data/news.json` and `news-images/`.

## Publishing a new news item
1. Upload the files to the same website directory as `styles.css` and `main.js`.
2. Open `admin-news.php`.
3. Create the article, add the official source, upload an image, and tick Published.
4. Save. The public Trade Intelligence page reads the updated JSON automatically.

## Important
This is a CMS-lite design for a static business website. It avoids a database and is easy to deploy. For a multi-user editorial system, roles, analytics, revisions, scheduling, media library and hundreds/thousands of articles, move the same fields into MySQL/Supabase/WordPress or another proper CMS.
